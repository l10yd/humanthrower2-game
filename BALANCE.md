# Диагностические сессии баланса

## Методика

10 естественных fixed-step demo-сессий: seeds **17, 42, 93, 20261111, 813**, каждый с двумя политиками:

- **idle**: без движения, прыжков и атак;
- **saw**: движение между краями, периодические прыжки, 7,5 отдельных нажатий/с при ragdoll, удержание пилы и прицел в ближайшую часть NPC.

Это **автоматические диагностические боты, не человеческий плейтест**. Прицел использует точные позиции мира. Не добавляются тестовые тела/ряды/неуязвимость, не отключаются столкновения и не меняются параметры игры. Лимит — 90 секунд игрового времени. Достигшие его сессии отмечены `censored`: их реальная длительность неизвестна, это не поражение.

Сервер запускается свежим через Playwright, чтобы исключить ранее обнаруженный stale Vite module cache. Сессии и промежуточные JSON-результаты сохраняются после каждого прогона.

## Запуск

Git Bash / Linux:

```sh
HUMANTHROWER_TEST_PORT=5187 HUMANTHROWER_TEST_FRESH=1 HUMANTHROWER_BALANCE_10=1 npm run balance:measure
```

PowerShell:

```powershell
$env:HUMANTHROWER_TEST_PORT='5187'
$env:HUMANTHROWER_TEST_FRESH='1'
$env:HUMANTHROWER_BALANCE_10='1'
npm run balance:measure
```

Выход: `.pi/balance-10-sessions-fixed.json`. Переменная `HUMANTHROWER_BALANCE_OUTPUT` задаёт другой путь. Команда намеренно отдельная от обычного browser suite.

Альтернатива для уже запущенного, проверенно актуального dev-сервера:

```sh
npm run balance:bot -- http://127.0.0.1:5173 .pi/balance-report.json 90
```

`Game.restart(seed)` принимает uint32, обычный `restart()` сохраняет seed; начальный seed по-прежнему20261111. Seed включён в результат/рекорд. Этот API нужен для воспроизводимости и не меняет пользовательский баланс.
