# Поверхности и UV при выпуклом срезе

## Данные

`Face` в `src/slicing/ConvexClipper.ts` хранит:

- `vertices: Vec3[]` — существующую физическую геометрию;
- `uvs?: SurfaceUv[]` — необязательные координаты `{u,v}` для **каждого угла этой грани**;
- `surfaceId?: string` — метку исходной поверхности, не материал и не physics ID;
- `cap?: boolean` — поверхность среза.

UV принадлежат углам граней, а не уникальным физическим вершинам: одинаковая позиция на двух гранях может иметь разные UV. Это сохраняет швы текстур. Physics по-прежнему объединяет только позиции; UV не меняют collider hull, плотность, массу или COM.

`validateFaceUvs` проверяет длину массива, отсутствующие элементы и конечность каждого `u/v`. Проверка выполняется до clipping, в том числе для no-op среза, и перед созданием render geometry. Малформатные массивы отклоняются; это не повод удалять физическое тело.

## Срез

- Уцелевший угол сохраняет свои UV.
- Пересечение ребра получает линейную интерполяцию UV с тем же параметром `t`, который использован для геометрической точки.
- Очистка дублирующих/коллинеарных позиций синхронно оставляет атрибуты сохранившихся углов.
- Метка исходной поверхности и предыдущий `cap` сохраняются. Исходный polyhedron не мутирует.
- Новая грань среза получает `surfaceId='cut'`, `cap=true` и плоские UV по двум ортогональным осям cut plane.

Проекция новой грани задаётся в body-local reference frame, без нормализации по текущему размеру/центру cap. Поэтому повторный срез не растягивает и не сдвигает оставшийся рисунок. Противоположные нормали используют одинаковый базис UV. Координаты могут выходить за диапазон0..1: это разрешено для повторяющихся текстур.

**Граница:** произвольные неаффинные UV большого n-gon сохраняются по рёбрам, но новая triangulation может изменить интерполяцию внутри polygon. Для production-ассетов такие грани должны иметь согласованный affine mapping или авторинг/триангуляцию, учитывающие будущие срезы. Pixel-equality fixture использует affine текстурирование; он не доказывает сохранение любого сложного UV unwrap.

## Renderer

`RetroRenderer.geometry` берёт UV из грани. Для старых граней без UV остаётся прежняя проекция `x*3+.5 / y*3+.5`, чтобы default NPC не меняли наружную поверхность. Новые caps используют свою двумерную проекцию — горизонтальный срез больше не сводится к одной линии текстуры.

Отключение крови меняет окраску/флаг поверхности, но не позиции, normals или UV. `surfaceId` пока **не** выбирает материал/атлас: художественные cut textures и наборы одежды ещё не подключены.

## Что остаётся

Полный surface-material/atlas pipeline, художественная текстура среза, authored GLB UV и их validator, normals/tangents других surface attributes, vertex/triangle budgets и ошибки всего asset load/export. `PLAN.md`/`CONNECTORS.md` описывают следующий этап. Это реализация атрибутов среза, **не** art-final и не закрытие физического angular gate.
