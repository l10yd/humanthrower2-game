# HUMANThrower — Chaos Survival Demo

Браузерная физическая survival-аркада с ретро-графикой: выживай в шахте, складывай падающие тела в ряды, подбирай оружие и переживай случайные катастрофы.

**[▶ Играть в демо](https://humanthrower-game.netlify.app)**

> 18+: кровь и расчленение. Все персонажи — взрослые. Количество крови можно уменьшить или выключить в настройках.

## Что есть в демке

- Высокая шахта **9 × 16**: твёрдые стены и пол, верх блокирует игрока. Трупы спавнятся целиком в скрытой зоне над кадром и входят через границу естественным падением. Остальные вылетевшие фрагменты удаляются; скрытый вход ограничен по времени и высоте.
- Падающие ragdoll-тела, живые/дёргающиеся NPC и физические куски, сохраняющие массу после разрезания.
- Заполненные ряды предупреждают штриховкой, яркими границами, обратным отсчётом и короткими звуковыми импульсами, затем очищаются. Голова/корпус в срезе — смертельно, потеря конечности не завершает игру.
- Прочность каждой части тела, хромота/ползание, воздух под завалом и QTE подъёма.
- При критическом повреждении голова или корпус **взрываются на фрагменты**, управление отключается; **2 секунды** физической сцены с лёгким блюром, затем плавно появляется поражение.
- Старт **без оружия**. Зелёные поставки оружия падают сверху; подойди, чтобы подобрать. Первая поставка — пила, затем виды перемешиваются без повторов в цикле. Выдаются только виды, которыми можно пользоваться с сохранившимися конечностями. Дальше поставки — каждые 8–13 секунд.
- Оружие, аптечки и небесные опасности тоже появляются вне кадра и входят через верхнюю маску. Подсветка колонны бомбы сохраняется до столкновения. После перезапуска визуалы предметов пересоздаются, даже если ID совпал с прошлым забегом.
- Пила, топор, меч, гранатомёт, рука Сварла, лопасти и голова Сварла. Найденное оружие изнашивается и ломается; гранатомёт имеет 8 зарядов.
- **8 случайных событий:** землетрясение, ливень тел, тяжёлая гравитация, бомба с неба, циркулярные пилы, падающий металлолом, боковой шквал и кислота. Предупреждение за 2 секунды; для бомбы подсвечивается опасная колонна, поставки выделены зелёным ореолом. События постепенно учащаются.
- **Кислота при большой куче:** когда накоплено минимум 100 физических частей, иногда выбирается кислотное событие. После предупреждения жёлтая жижа поднимается снизу максимум на 1,6 м, держится несколько секунд и уходит. Погружённые тела/обломки растворяются; верхние части остаются, игрок получает урон — забирайся выше. Это видимая игровая расчистка, не скрытое удаление ради FPS.
- **Аптечки сверху:** первая на 18-й секунде, дальше каждые 22 секунды. Восстанавливают до 25 процентных пунктов прочности сохранившихся частей и 2 секунды воздуха. Не отращивают конечности и не воскрешают.
- Попадания опасностей учитывают анатомию и защиту после подъёма; твёрдые стены блокируют урон бомбы.
- **Новая сессия** выбирает новый seed — события и тела меняются между попытками. Для воспроизводимых тестов сохранён `game.restart(seed)`.
- Читаемый HUD: очки, время, ряды, прочность и воздух. Диагностика и тестовые кнопки доступны с `?debug`.
- Таблица локальных рекордов в меню, подробный итог забега и **T — повторить тот же seed** с исходными настройками. Очки за ряды и время показаны отдельно; результат не меняется во время сцены смерти.
- Очки, комбо, рекорды в браузере, обучение, пауза, настройки звука/графики и сенсорные кнопки.

## Управление

| Кнопка | Действие |
|---|---|
| A / D, ← / → | Движение |
| Space / W / ↑ | Прыжок; под завалом — быстро нажимай для подъёма |
| S / ↓ | Придавить в падении |
| E / ЛКМ | Атаковать найденным оружием |
| ПКМ | Тычок мечом или топором |
| Q | Следующее найденное оружие |
| F | Убрать / достать оружие |
| Esc / P | Пауза и настройки |
| T на экране поражения | Повторить завершённый seed |
| R | Новая попытка |

Цель — продержаться дольше и набрать больше очков, очищая ряды. Уходи из мигающих полос и следи за предупреждениями событий. На телефоне доступны экранные кнопки.

## Локальный запуск

Нужен Node.js **22.12+** и браузер с WebGL2.

```bash
npm ci
npm run dev
```

Открыть `http://127.0.0.1:5173`.

```bash
npm run build                       # TypeScript + production bundle
npm test                            # полный набор unit/physics проверок
npx vitest run tests/physics/chaos-demo.test.ts
npx playwright install chromium
npm run test:demo                   # механики + браузерные сессии демки
npx playwright test tests/browser/chaos-demo.spec.ts tests/browser/chaos-polish.spec.ts tests/browser/medical-hazards.spec.ts
npm run test:performance             # large-world recovery / opt-in profiler
npm run profile:default -- test-results/default-profile.json # production CPU/render diagnostic
npm run test:mvp                     # строгий unit/physics + build + полный browser gate
```

Полная физическая батарея содержит строгие исследовательские проверки больших куч (скорости вращения/поддержка KCC); они не являются обещанием окончательно устойчивой физики. Демка остаётся экспериментальной. Новые механики отдельно покрыты `chaos-demo` тестами.

## Текущий путь к MVP

Актуальный default-контракт и проверяемый backlog: **[docs/MVP_PLAN.md](docs/MVP_PLAN.md)**. Исходная ревизия: [docs/DEMO_AUDIT.md](docs/DEMO_AUDIT.md).

Первый performance-проход ускорил расчистку при подъёме, добавил пространственный индекс collision queries и исправил выход обломков выше чаши. Второй объединил body blood decals в один draw call, ускорил occupancy и исправил crash сцены смерти после смертельного среза. Текущий релиз добавляет кислотное событие и правила рекордов `3.8-acid-pile-event`. Перед этим выполнены CPU/render оптимизации и исправления регрессий; исследовательские native-кандидаты отвергнуты, production Rapier не заменён. Подробная история: [docs/MVP_CHECKPOINT_3.md](docs/MVP_CHECKPOINT_3.md), [docs/MVP_CHECKPOINT_4.md](docs/MVP_CHECKPOINT_4.md). Строгие angular gates пока не закрыты; игра остаётся экспериментальной. Численные physics gates остаются открыты: это пока не заявление о готовом MVP.

`?profile` включает ограниченную CPU-диагностику: `window.humanthrower.profiler.snapshot`. По умолчанию расширенный сбор выключен. Метрики вложены; их p95 нельзя суммировать. `?debug` по-прежнему показывает диагностический HUD.

## Технологии и структура

**TypeScript · Three.js · Rapier 3D · Vite · Vitest · Playwright**

- `src/core/Game.ts` — игровой цикл и состояния.
- `src/gameplay/ChaosDirector.ts`, `SkyDrops.ts` — события и падающие предметы.
- `src/gameplay/WeaponInventory.ts`, `WeaponController.ts` — инвентарь, атаки и прочность.
- `src/gameplay/DeathSequence.ts` — фрагментация при смерти.
- `src/physics/`, `src/player/`, `src/slicing/` — физика, игрок и разрезание.
- `assets/blender/` — исходники Blender; `public/assets/` — модели для браузера.
- `tests/` — геометрия, физика и браузерные проверки.
